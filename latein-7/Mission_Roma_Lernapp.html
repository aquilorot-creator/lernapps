Personalendungen: -o = ich, -s = du, -t = er/sie/es, -mus = wir, -tis = ihr, -nt = sie (Plural).

Akkusativfrage: wen oder was? Beispiele: amicum / amicos, amicam / amicas, donum / dona. Beim Neutrum sind Nominativ und Akkusativ gleich. Der Satz entscheidet über die Funktion.

Besonderheiten: saluta + o → saluto; veni + u + nt → veniunt. Esse: sum, es, est, sumus, estis, sunt.
